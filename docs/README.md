## 各子目录受众

| 路径 | 受众 | 说明 |
|------|------|------|
| `CODEMAPS/` | AI 助手 / 维护者 | 仓库架构地图（architecture / backend / data / dependencies）。普通用户可跳过；维护重构时建议先读 |

> 竞品调研属内部材料，可能随生态变动而过时；用户请以 README 为准。
